# Frontpage

A self-retraining ML system that predicts which Hacker News stories will reach 100 points, scores every new story within minutes, and grades itself 24 hours later.

Runs on a single 2 vCPU / 4 GB Linode with k3s, Argo CD, MLflow, DVC, KServe and Prometheus/Grafana.

Status: under construction (Oct 27 - Nov 5, 2026).
